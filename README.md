# MGTS Infra Vision

Прототип системы мониторинга городской инфраструктуры МГТС по снимкам с камер служебных автомобилей.
Находит кабельные колодцы, опоры и т.п., оценивает состояние, выдаёт перечень объектов для проверки/ремонта с координатами.

## Как устроен репозиторий

```
AGENTS.md                 правила для всех агентов (читать первым)
tasks/                    персональные задания: agent_1..agent_4 + чеклист «день 0»
docs/                     архитектура, контракты данных, API_SPEC (низкоуровневая спецификация), критерии дефектов, демо
skills/review/            слот под скилл ревью (положить свой SKILL.md)
configs/                  classes.yaml (классы и дефекты), default.yaml (пороги и пути)
src/mgts/                 пакет
  schemas.py              ЗАМОРОЖЕННЫЕ контракты данных (общие для всех)
  config.py               загрузка конфигов
  data/                   конвертация, сплит, аугментации, синтез дефектов   (Агент 1)
  preprocessing/          качество кадра, CLAHE/gamma                          (Агент 2)
  detection/              обучение и инференс детектора, SAHI, оценка          (Агент 2)
  condition/              геометрия, классификатор, скоринг состояния          (Агент 3)
  geo/                    GPS/EXIF, проекция в координаты, дедупликация        (Агент 4)
  pipeline.py             сквозной пайплайн                                    (Агент 4)
  export.py               CSV / GeoJSON / HTML-отчёт                           (Агент 4)
  cli.py                  команды mgts ...                                     (Агент 4)
app/streamlit_app.py      веб-интерфейс                                        (Агент 4)
scripts/                  вспомогательные скрипты
tests/                    pytest
```

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install -e .
pytest -q                       # контракты проходят, заглушки = skipped
make red                        # TDD-режим: заглушки считаются упавшими (MGTS_STRICT=1)
make green                      # приёмка: всё зелёное, без пропусков
```

## Сквозной запуск (цель проекта)

```bash
mgts run --input data/raw/images --output outputs/run1      # перечень + карта
streamlit run app/streamlit_app.py                           # демо-интерфейс
```

## Порядок работы на хакатоне

1. Прочитать `AGENTS.md` и `docs/ARCHITECTURE.md`.
2. Выполнить `tasks/00_day0_checklist.md` (когда придёт датасет) — делает человек + Агент 1.
3. Каждый агент берёт свой файл `tasks/agent_N_*.md` и работает в своей ветке в своих директориях.
4. Интеграция: Агент 4 регулярно мержит ветки и гоняет `make e2e`.
