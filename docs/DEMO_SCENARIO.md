# Сценарий демонстрации (5–7 минут)

> Финальную версию обновляет Агент 4 после интеграции. Здесь — каркас.

1. **Проблема (30 с).** Бригады МГТС объезжают город вслепую; камеры автомобилей уже снимают улицы.
2. **Вход (30 с).** Загружаем папку кадров (+ GPS-трек) в веб-интерфейс.
3. **Обработка (1 мин).** Прогресс-бар; показываем один кадр «до/после»: рамки, цвет по состоянию.
4. **Перечень (1 мин).** Таблица, отсортированная по приоритету; фильтр «требует проверки»; скачать CSV.
5. **Объяснимость (1 мин).** Выбираем объект → кроп + «наклон 9.3° > порога 8°» / «ржавчина 31 % поверхности».
6. **Карта (1 мин).** Маркеры по приоритету, всплывающее окно с миниатюрой; GeoJSON открывается в ГИС.
7. **Как справились со сложностями (1 мин).** Нет данных → синтез дефектов + геометрия; мелкие объекты → тайлинг;
   повторные кадры → дедупликация; неуверенность → `needs_review`.
8. **Метрики (30 с).** mAP/recall детектора, recall по дефектным объектам, скорость мс/кадр.
9. **Дальше (30 с).** Дообучение на реальных данных МГТС, интеграция с ГИС/нарядами, работа с видеопотоком.

## Подготовить заранее
- `outputs/demo_final/` с готовым результатом на реальном датасете (на случай проблем с запуском вживую);
- 3–4 «красивых» кадра: чёткий дефект, пограничный случай, ошибка модели (честно показать ограничение);
- таблица метрик из `docs/DETECTION_REPORT.md` и `models/condition_metrics.json`;
- запасной скринкаст 60 с.
