# Слот под скилл ревью

Положите сюда ваш `SKILL.md` (и вспомогательные файлы) — агенты вызывают его на шаге 6 цикла TDD (`tasks/TDD.md`)
и перед каждым мержем ветки.

## Как подключить
- Claude Code: скопируйте папку в `.claude/skills/review/` (или оставьте здесь и укажите путь в промпте агента).
- Другие агенты: добавьте в промпт строку «Перед коммитом выполни ревью по инструкции из `skills/review/SKILL.md`».

## Минимум, если своего скилла нет
Проверить: (1) сигнатуры совпадают с `docs/API_SPEC.md` и `# CONTRACT`; (2) нет «магических» чисел — всё в конфиге;
(3) функция не падает на пустом/мелком входе; (4) есть тесты на границы; (5) не тронуты чужие файлы; (6) нет мусора и отладочных print.
