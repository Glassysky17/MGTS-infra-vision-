# День 0: что делать, когда придёт датасет

Делает человек вместе с Агентом 1 (до запуска остальных агентов — 15–20 минут).

## 1. Осмотр (5 мин)
- [ ] Положить данные в `data/raw/` (ничего не удалять, исходники не править).
- [ ] Формат разметки: YOLO txt / COCO json / VOC xml / CSV / нет разметки?
- [ ] Классы организатора — выписать список.
- [ ] Есть ли метки состояния/дефектов (классы вида «broken_manhole», атрибуты, отдельные папки ok/defect)?
- [ ] Есть ли GPS: EXIF, отдельный CSV/GPX, имена файлов с координатами/временем? Видео или кадры?
- [ ] Посмотреть вручную 20–30 разных кадров: ракурс, разрешение, ночь/дождь, насколько мелкие объекты.

## 2. Определить сценарий данных

| Сценарий | Признак | Что делаем |
|---|---|---|
| **A. Есть дефектные метки** | дефекты — классы или атрибуты | детектор обучаем на объектах; дефекты → классификатор по кропам (метки реальные) + геометрия как дополнение |
| **B. Только объекты, дефектов нет** | один класс «колодец», «опора» без состояния | геометрия (наклон, форма люка, трещины, ржавчина) + синтез дефектов для классификатора; честно писать в отчёте, что дефекты — эвристики |
| **C. Нет разметки вообще** | только картинки | разметка вручную 150–300 кадров в CVAT/Label Studio (полуавтомат: черновик предобученной YOLO → правка); параллельно A3 работает на синтетике |

Записать выбранный сценарий в начало `docs/DATASET_REPORT.md`.

## 3. Настроить классы (5 мин)
- [ ] Править `configs/classes.yaml`: имена классов и их `id` = порядок в YOLO; убрать лишние, добавить нужные.
- [ ] Для каждого класса — список реально различимых дефектов (`defects`); убрать те, что на кадрах не видны.
- [ ] Обновить `docs/DEFECT_CRITERIA.md` (таблица) и `tests/test_config.py` не ломать (дефекты класса ⊂ справочника).
- [ ] Для `convert_to_yolo` подготовить `class_map` организатора → имена из `classes.yaml`.

## 4. Подготовка (Агент 1, первые 30 минут работы)
- [ ] `mgts analyze --dataset data/raw` → `docs/DATASET_REPORT.md`.
- [ ] `mgts prepare --src data/raw --fmt auto` → `data/processed`, `train.txt/val.txt`, `data/crops`.
- [ ] Поправить в `default.yaml → dataset.group_by` правило группировки серий кадров.
- [ ] Выписать в отчёт: дисбаланс классов, доля мелких объектов, условия съёмки → это вход для A2/A3.

## 5. Калибровка (Агент 2, когда есть кадры)
- [ ] `calibrate_blur_threshold` на реальных кадрах → `preprocessing.blur_threshold`.
- [ ] Решить, нужен ли тайлинг (если медиана размера bbox < 40 px — да).

## 6. Решение по GPS
- Есть EXIF/трек → ничего не делаем, A4 использует.
- Нет → оставить `fallback_no_gps: synthetic` и **явно** писать на защите, что координаты демонстрационные.

## 7. Старт агентов
Создать ветки, закоммитить, запустить 4 агентов по `tasks/README.md`.
