# Следующий этап: проверка на реальных данных

## Статус

Код прототипа реализован и покрыт тестами. Входных реальных данных пока нет. Файлы `agent_1_data.md`–`agent_4_integration.md` теперь содержат планы проверки, обучения и калибровки; они не требуют повторно создавать уже существующие модули.

Демо с `dummy` проверяет только интеграцию. Его цифры нельзя выдавать за точность модели или качество эвристик на реальных кадрах.

## До получения датасета

```bash
make install-dev
make green
make demo-data
make e2e
```

Для Streamlit и обучения моделей установите полный набор: `make install`.

## Когда датасет появится

Первое поручение агенту:

> Положи предоставленные данные в `data/raw/`, выполни только `mgts analyze --dataset data/raw`, сверь имена и порядок/ID классов с `configs/classes.yaml`, проверь группировку серий по именам кадров. Покажи отчёт и найденные проблемы; не запускай `prepare` или обучение до моего подтверждения.

1. Сохранить исходные данные в `data/raw/`, не изменяя оригиналы; выполнить только `mgts analyze --dataset data/raw`.
2. Сверить имена и порядок/ID классов в `configs/classes.yaml` с разметкой; проверить по именам файлов, что `dataset.group_by: sequence` не смешает соседние кадры между train и val.
3. Показать отчёт и несоответствия пользователю, затем остановиться. Не запускать `prepare`, `train-det` или `train-clf`, пока пользователь не подтвердит продолжение.
4. После подтверждения подготовить датасет и проверить split на утечки; затем скачать базовые веса и обучить детектор.
5. Оценить recall по классам (`mgts eval-det --split val`), особенно редким, и проверить ошибки на реальных кадрах. Приоритет — не пропускать дефекты.
6. Вручную откалибровать пороги размытия, наклона, трещин и геометрию камеры для GPS-проекции. Детектор учится на рамках/классах; обучение классификатора состояния возможно отдельно, только при наличии кропов с метками `ok`/дефект.
7. Прогнать пайплайн на отложенных данных и зафиксировать метрики и ограничения в отчётах.

Не запускать обучение и не менять пороги по синтетическому демо.
