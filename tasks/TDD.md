# Проверки изменений

Проверяйте поведение, которое меняется, на актуальных входах. `NotImplementedError` не является штатным способом пропустить тест: незавершённая реализация должна приводить к обычному падению.

```bash
pytest tests/test_<module>.py
make green
make demo-data && make e2e
```

- Для новой ветки логики добавить тест на ожидаемый результат и значимый крайний случай.
- Для регрессии сначала добавить тест, воспроизводящий исходную ошибку.
- После обновления зависимостей проверить `uv lock --check`.
- Сквозное демо использует синтетические кадры и `dummy`; оно не заменяет проверку модели на реальных размеченных данных.
