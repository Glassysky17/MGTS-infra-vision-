## Порядок задач

### §0. `scripts/make_demo_data.py` — ПЕРВЫМ (≤ 15 минут)
От него зависят `make e2e`, тесты и отладка у остальных. Реализуй по докстрингу файла.
Требования, которые не очевидны:
- сцена «улица» должна быть хотя бы правдоподобной: горизонт на ~40% высоты кадра, асфальт ниже, объекты на земле
  в нижней половине кадра (иначе проекция Агента 4 вернёт None); размер люка уменьшается с удалением (перспектива);
- координаты: трек вдоль прямой, шаг 3–5 м, курс постоянный; **один и тот же физический объект виден в 2–3 соседних кадрах**
  (с корректно сдвинутой позицией в кадре) — это тест дедупликации;
- `gt_defects.csv`: хотя бы 25% объектов дефектные (трещины на люке, опоры с наклоном > 8°);
- итого ≥ 3 разных объекта на 16 кадрах; детерминированно по `--seed`.
Критерий: `pytest tests/test_pipeline_e2e.py::test_demo_data_layout` проходит.

### §1. `analyze.py` — анализ датасета
Реализуй `analyze_dataset`. Выведи в отчёт «Выводы для дня 0» (см. докстринг). Кроме Markdown-отчёта сохрани картинку
с примерами. Добавь в начало отчёта выбранный сценарий данных (A/B/C из `tasks/00_day0_checklist.md`).

### §2. `convert.py` — конвертер
Форматы: YOLO (копирование + проверка), COCO json (`bbox` = [x, y, w, h] в пикселях), Pascal VOC xml, CSV
(`filename, class, xmin, ymin, xmax, ymax`). Маппинг классов через `class_map`; неизвестные — в `unmapped_classes.txt`.
Автоопределение формата. Битые рамки не терять молча.
Тест: `test_convert_coco_to_yolo`.

### §3. `split.py` — сплит без утечек
Группировка кадров одной серии (по умолчанию префикс имени до последнего числового блока; для видео-кадров — блоки
по N=30 последовательных). Стратификация по редким классам. Детерминизм. Обновить `data.yaml`.
Тест: `test_make_split_no_group_leak`.

### §4. `crops.py` — вырезки для классификатора
Раскладка по `split/class/label`, `index.csv`. Если меток состояния нет — класть в `unlabeled`.

### §5. `augment.py` — физически правдоподобные аугментации
Реализуй все функции из файла на numpy/OpenCV. Требования:
- motion blur: линейное ядро нужной длины и угла (`cv2.filter2D`), нормировка суммы ядра = 1;
- дождь: штрихи с наклоном ≈ 70–80°, прозрачность, лёгкое размытие, потеря контраста;
- блик: гауссово пятно + bloom по яркой маске;
- тень: многоугольник с мягким краем (GaussianBlur по маске), множитель яркости 0.4–0.8;
- ночь: гамма > 1, затемнение, холодный сдвиг, шум матрицы;
- `perspective_warp`: гомография из случайных смещений углов (`max_shift` доли кадра), рамки трансформировать
  через ту же матрицу и взять охватывающий прямоугольник; вернуть только рамки, оставшиеся в кадре.
`build_train_augmentations(cfg)` — композиция со случайными вероятностями из `cfg.dataset.augment`
(добавь секцию с вероятностями в `default.yaml`) + CLI для офлайн-балансировки редких классов.
Тест: `test_augmentations_*`, `test_perspective_warp_*`.

### §6. `synth_defects.py` — синтетические дефекты
Реализуй `synth_cracks`, `synth_rust`, `synth_tilt`, `synth_displaced_cover`, `generate_synthetic_defects`.
Дефекты должны выглядеть правдоподобно, иначе классификатор Агента 3 выучит «артефакты синтеза», а не дефекты:
- трещины: ветвящееся случайное блуждание, переменная толщина (1–3 px), тёмный цвет с мягкими краями, смешивание по альфе;
- ржавчина: шум (сумма октав блюра случайного поля) → порог → маска → оранжево-коричневый цвет с текстурой оригинала;
- наклон: аффинный поворот вокруг основания, фон под объектом закрыть `cv2.inpaint`;
- сохраняй метаданные в `index.csv`, колонка `synthetic=1`.
Тесты: `test_synth_*`.
