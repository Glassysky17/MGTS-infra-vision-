# Детекция: обучение и проверка качества

Предобработка, `DummyDetector`, YOLO-инференс, тайлинг, обучение и оценка реализованы в `src/mgts/preprocessing/` и `src/mgts/detection/`. Не дорабатывать их без воспроизводимой проблемы.

После подготовки реальных данных:

1. Установить полный набор зависимостей (`make install`) и скачать `models/yolov8s.pt` по команде из README.
2. Обучить модель командой `mgts train-det`.
3. Проверить отложенную выборку командой `mgts eval-det --split val`; сравнить результаты с тайлингом и без него.
4. Откалибровать `detection.conf` и `preprocessing.blur_threshold` на реальных кадрах, а не на `dummy`.
5. Записать метрики, типовые false positive/negative и скорость в `docs/DETECTION_REPORT.md`.

**Результат:** метрики только на размеченной выборке и явное описание её ограничений. Без размеченных данных обучение и выводы о качестве не выполнять.
