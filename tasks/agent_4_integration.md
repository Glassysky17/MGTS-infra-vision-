# Интеграция: проверка на реальном маршруте

GPS, дедупликация, пайплайн, экспорт, CLI и Streamlit уже реализованы. `pipeline.py` сохраняет ошибки кадров в `summary.json`; `dummy` служит для демо с готовой разметкой, не заменяет детектор.

После подготовки датасета и обучения:

1. Запустить `mgts run --input ... --track ... --output outputs/real-run --backend yolo` на отложенных реальных кадрах.
2. Проверить CSV, GeoJSON и карту: неизвестные GPS должны оставаться неизвестными, приблизительные — помечаться.
3. Изучить `summary.json`, включая `frame_errors`; проверить причины сбоев и повторно прогнать исправленные кадры.
4. Сопоставить объекты после дедупликации с кадрами, проверить не менее 30 результатов и ложные объединения/разделения.
5. Для UI установить полный набор зависимостей и проверить загрузку фото/трека, запуск и скачивание результатов.
6. Записать фактические метрики и ограничения в `docs/DEMO_SCENARIO.md` и README.

**Результат:** воспроизводимый прогон на реальных данных с проверенными артефактами. Демо с `dummy` не считать подтверждением качества.
