## Порядок задач

### §1. `geo/gps.py`
`read_exif_gps` (Pillow, N/S/E/W, рациональные числа, `GPSImgDirection`), `load_track_csv` (терпимо к `;` и именам
колонок), `load_track_gpx` (gpxpy или `xml.etree`), `interpolate_position` (курс по кратчайшей дуге!),
`build_frame_meta` с приоритетом источников из докстринга и размерами через Pillow без полной загрузки.
Тесты: `test_interpolate_*`, `test_load_track_csv_*`, `test_build_frame_meta_*`.

### §2. `geo/project.py` — проекция на землю (задача про геометрию камеры)
Модель обскуры: `f = (W/2) / tan(hfov/2)`, луч `(x, y, z) = ((u−cx)/f, (v−cy)/f, 1)`, поворот на `pitch`, пересечение
с плоскостью земли на высоте камеры. Дальше: повернуть `(вперёд, вправо)` на курс → `(север, восток)` →
`utils.offset_latlon`. Выше горизонта и >60 м → `None`, тогда вернуть позицию автомобиля с суффиксом `_approx`.
Параметры камеры (`height_m`, `pitch_deg`, `hfov_deg`) — в конфиге; на день 0 спроси организаторов или оцени
по кадрам и зафиксируй допущение в README.
Тесты: `test_ground_projection_*`, `test_object_position_*`.

### §3. `geo/dedup.py`
Union-find по расстоянию (haversine) внутри класса + проверка внешнего вида (HSV-гистограммы кропов, пропускать, если
кропов нет или `use_appearance=false`). Наблюдения без координат — по соседству кадров и IoU рамок. Агрегация:
лучшее наблюдение (score × резкость), медиана координат, объединение findings, `priority_for` из `condition.scoring`,
присвоение `OBJ-0001…` по убыванию приоритета.
Тесты: `test_dedup_*`.

### §4. `pipeline.py`
`run_pipeline` по докстрингу. Принципы: ошибка одного кадра не роняет запуск; детектор создаётся один раз;
`enhance` только для детектора, оценка состояния — по оригиналу; `progress`-callback; `summary.json` со временем по
этапам. Первое рабочее состояние — с `DummyDetector` и заглушечной оценкой (`assess` может быть ещё не готова —
оберни в try/except с понятным предупреждением, чтобы e2e шёл по частям).
Тест: `test_pipeline_end_to_end`.

### §5. `export.py`
`to_csv` (UTF-8 BOM + `title_ru`), `to_geojson` (`[lon, lat]`!), `to_html_map` (folium; маркеры по приоритету, миниатюра
кропа base64, пометка ручной проверки, легенда, фильтр слоёв; fallback без folium), `draw_annotated`.

### §6. `cli.py`
Каркас готов — подключи реальные вызовы. Пользовательские ошибки (нет папки/весов) → понятное сообщение и `return 2`.
`mgts run` печатает краткую сводку («Найдено 14 объектов: 2 critical, 3 high, 4 нужна проверка»).
Тесты: `test_cli_run`, `test_cli_missing_input_is_friendly`.

### §7. `app/streamlit_app.py`
Реализуй по макету из докстринга файла. Приоритеты: (1) загрузка → запуск пайплайна → таблица + скачивание CSV/GeoJSON,
(2) карта, (3) галерея аннотированных кадров и объяснение (evidence), (4) сводка. Кэшируй результаты.
Если координаты синтетические — заметная плашка.

### §8. Интеграция (с T+40 и до конца)
- Мерж веток в порядке 1 → 2 → 3 → 4, после каждого `pytest && make e2e`.
- Прогон на реальном датасете (не только demo): `mgts run --input data/raw/... --output outputs/real`.
- Совместно с A2/A3 подбери пороги на val-кадрах, посмотри 30 найденных объектов глазами, отметь типичные ошибки.
- Сохрани готовый результат в `outputs/demo_final/` для защиты.
- Обнови `README.md`: как запустить, допущения (параметры камеры, источник GPS), метрики, ограничения.
- Заполни `docs/DEMO_SCENARIO.md` реальными цифрами.

## Критерии приёмки
- [ ] `pytest` без падений, `make e2e` отрабатывает за < 2 минут на 40 кадрах.
- [ ] `mgts run` на реальных данных создаёт `objects.csv`, `objects.geojson`, `map.html`, `annotated/`, `summary.json`.
- [ ] Дедупликация реально сокращает число объектов (в тесте `len(records) < n_detections`).
- [ ] Streamlit-демо запускается и показывает таблицу, карту и объяснения.
- [ ] README позволяет чужому человеку запустить всё за 5 минут.

## Fallback
- Нет folium: `map.html` на чистом Leaflet через CDN-скрипт (маркеры из GeoJSON), либо HTML-таблица.
- Нет GPS и трека: синтетические координаты с пометкой `synthetic` в CSV/карте/интерфейсе — и честная плашка в демо.
- Streamlit не взлетает: Gradio или статический `map.html` + `objects.csv` как итог (CLI — основной режим демо).
- Агент по состоянию (A3) не успел: pipeline работает с пустой оценкой (`severity=ok`), видно только детекции —
  в этом случае сообщи человеку, это критичный риск.
